# 첫단추 시연용 원장 생성기

하늘(가족 A, 진행 중)과 바다(가족 B, 확인서 발급)의 **원장**을 만드는 도구예요.
원장은 돈이 움직인 기록을 시간 순서로 한 줄씩 적은 표이고, 앱의 모든 숫자(잔액, 청구 예정, 완납, 확인서)는 여기서 계산돼요.

시연 데이터를 만드는 일회용 도구라 서비스 코드에는 들어가지 않아요.

## 1. 실행하기

Python 3.11 이상만 있으면 돼요. 추가 설치는 없어요.

```bash
python3 --version        # 3.11 이상인지 확인
python3 generate.py      # 이 폴더에서 실행
```

이렇게 나오면 성공이에요.

```
가족 A 하늘: 원장 247줄, 정산 11번, 완납 10번, 지금 연속 6개월  ✅ 이야기대로
가족 B 바다: 원장 516줄, 정산 27번, 완납 24번, 지금 연속 15개월  ✅ 이야기대로
```

## 2. 결과 파일 (`out/` 폴더)

| 파일 | 누가 쓰나 | 내용 |
|---|---|---|
| `report.md` | 모두 | 이야기대로 나왔는지 확인표, 월별 요약, 기준일 숫자 |
| `family_a/원장.csv` | 사람 | 엑셀로 열어보는 원장 |
| `family_a/월별요약.csv` | 사람·백엔드 | 달마다 용돈, 청구액, 완납/부족, 모은 돈 |
| `family_a/seed.json` | **백엔드** | 페르소나 + 계좌 + 원장 + 미션 + 정답지를 한 파일에 |
| `family_a/ledger.json` | 백엔드 | 원장만 |
| `personas.json` | **백엔드** | 계정 선택 화면의 네 명 (`GET /personas`) |

`family_b/`도 같은 구성이에요.

**백엔드에 넘길 것**: `personas.json`, `family_a/seed.json`, `family_b/seed.json` 세 개.

`seed.json` 안의 `reference`는 **정답지**예요. 백엔드의 지표 엔진이 원장으로 직접 계산한 값이 이 숫자와 같으면 엔진이 맞게 만들어진 거예요. 화면에는 정답지가 아니라 엔진이 계산한 값을 써 주세요.

## 3. 이야기를 바꾸고 싶을 때

`config.toml`만 고치고 다시 실행하면 원장 전체가 새로 맞춰져요.

| 바꾸고 싶은 것 | 고칠 곳 |
|---|---|
| 용돈 금액이나 오르는 시점 | `allowance = [...]` |
| 심부름 보상 | `missions_paid = [...]` |
| 지금 진행 중인 미션 (미션 화면) | `missions_now = [...]` |
| 특정 달에 부족이 나게 | `[[family.month]]` 에 `result = "부족"`, `shortfall`, `resolve` |
| 특정 날 큰 지출 | `[[family.month]]` 의 `events = [...]` |
| 평소에 얼마나 아껴 쓰나 | `spend_ratio` (들어온 돈 중 쓰는 비율) |
| 데모 기준일 | `[demo] today` |
| 매일 결제를 다른 모양으로 | `[demo] seed` 숫자만 바꾸기 |

이야기가 규칙과 안 맞으면(예: 다음 용돈일보다 늦게 갚기) 무엇이 문제인지 알려주고 멈춰요.

## 4. 원장 규칙

- 정산 기간: 전달 26일 ~ 이번 달 25일
- 매월 1일 용돈 → **이번 달 용돈** 주머니
- 카드로 쓰면 바로 빠지지 않고 **청구 예정**으로 쌓임
- 25일 18:00 자동 정산: 이번 달 용돈 주머니에서만 빠짐
- 남은 돈 → **모은 돈** 주머니로 옮김 (같은 계좌 안, 이체 아님)
- 모자라면 부족분: 다음 용돈 전까지 아이가 직접 보내면 "스스로 해소", 못 보내면 다음 용돈에서 자동 정산
- 미션 보상 → 이번 달 용돈 주머니

## 5. 원장 한 줄의 모양 (`ledger.json`)

```json
{"id": "A-00246", "date": "2026-10-17", "time": "10:03",
 "type": "CARD_PAYMENT", "type_label": "카드 결제", "amount": 22000,
 "from": "가족카드", "to": "드럭스토어", "category": "선물", "merchant": "드럭스토어",
 "memo": "친구 생일 선물", "cycle": "2026-10", "for_cycle": "", "verified": "L2"}
```

| type | 뜻 | 돈의 움직임 |
|---|---|---|
| ALLOWANCE | 용돈 입금 | 부모 계좌 → 이번 달 용돈 |
| MISSION_REWARD | 미션 보상 | 부모 계좌 → 이번 달 용돈 |
| CARD_PAYMENT / CARD_CANCEL | 카드 결제 / 취소 | 청구 예정에 더하기 / 빼기 |
| SETTLEMENT | 결제일 정산 | 이번 달 용돈 → 부모 계좌 |
| SHORTFALL | 부족 발생 | 돈은 안 움직임 (기록만) |
| SHORTFALL_REPAY | 부족분 송금 | 이번 달 용돈 또는 모은 돈 → 부모 계좌 |
| AUTO_RECOVERY | 자동 정산 | 이번 달 용돈 → 부모 계좌 |
| POCKET_MOVE | 남은 돈 옮김 | 이번 달 용돈 → 모은 돈 |

`cycle`은 그 줄이 속한 정산 달, `for_cycle`은 부족분을 갚거나 자동 정산할 때 어느 달 부족분인지예요.
